# OSM 좌표 매칭 리포트

오피넷 키 없이 OpenStreetMap에서 채운 좌표입니다. **근사 출처이므로 검토가 필요합니다.**

- 좌표 확보: **65곳** / 대상 446곳
- 상호가 완전히 같지는 않은 건: **0곳** (표 위쪽)

판정 근거는 둘입니다. (1) 좌표가 해당 시·군·구 폴리곤 안에 있을 것,
(2) 그 지역 안에서 상호가 충분히 닮았을 것. 지역을 먼저 확정하므로 `행복주유소` 같은
흔한 상호가 다른 지역과 섞이지는 않지만, **같은 지역 안에서는 잘못 붙을 수 있습니다.**

틀린 건은 `data/station-coords.json` 에서 해당 항목을 지우면 핀이 사라집니다.
오피넷 키를 등록하면 `npm run coords` 가 전량을 정확한 값으로 덮어씁니다.
